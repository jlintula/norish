# v0.24.0-beta

## Summary

This release rebuilds the realtime layer underneath the app. Nothing changes in
how you use Norish: groceries, stores, recipes, cookbooks, the calendar,
households and CalDAV keep updating live between browsers as before. What
changes is what happens around a bad connection, a server restart and a reverse
proxy — and self-hosters have two upgrade notes to read.

## Fixes and Improvements

- Events you missed while disconnected now arrive when you reconnect. A phone
  that spent a minute in a tunnel receives the groceries a housemate added in
  the meantime, in order, without a reload; the full refetch still runs behind
  it, so a client away for longer than a day is caught up that way instead.
- A server restart with browsers connected completes in seconds instead of
  waiting out a thirty-second timeout. Connected clients are told the server is
  restarting, reconnect with backoff once it is back, and receive what they
  missed.
- An expired session ends at the sign-in page rather than in a reconnect loop.
- A validation failure on your own change toasts you alone, not the whole
  household.
- The number of Redis connections the server holds no longer grows with the
  number of open browser tabs.

## Upgrade notes

- **WebSocket upgrades are checked against their `Origin`.** A browser is
  accepted when its origin is `AUTH_URL`, an entry of `TRUSTED_ORIGINS`, or the
  host the request arrived on. If your reverse proxy rewrites the `Origin`
  header, or Norish is reached under a name that is neither `AUTH_URL` nor the
  request host, list the public origin in `TRUSTED_ORIGINS` or realtime updates
  stop while the rest of the app keeps working. See
  [WebSocket & realtime](../configuration/websocket.md), which also documents
  the reverse-proxy settings and the idle timeout the proxy must exceed.
- **The mobile app is parked and unsupported on this release.** It has not been
  carried through the rebuild and is expected to break against a 0.24 server
  until its own rewrite ships. The web app on a phone browser keeps working.
